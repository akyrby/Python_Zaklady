# Python Základy

Vítejte v projektu Python Základy! Toto úložiště obsahuje základní koncepty a cvičení z Pythonu, které vám pomohou začít s tímto jazykem.

## Obsah

### 1. Proměnné (`1_promenne.py`)
Úvod do proměnných a jejich přiřazování v Pythonu.
- Deklarace proměnných a konvence pojmenování
- Různé způsoby přiřazení hodnot
- Rozsah a doba životnosti proměnné

### 2. Datové typy (`2_Datove_typy.py`)
Prozkoumání vestavěných datových typů Pythonu.
- Řetězce (strings)
- Čísla (celá čísla a desetinná čísla)
- Booleovské hodnoty
- Konverze typů a kontrola typů

### 3. Datové struktury/Data structures (`3_Datove_struktury.py`)
Pokročilé datové typy
- Seznam (list)
- n-tice (tuple)
- Množina (set)
- Slovník (dictionary)

## Začínáme

### Požadavky
- Python 3.7 nebo vyšší nainstalovaný ve vašem systému

### Spuštění souborů

Přejděte do adresáře projektu a spusťte jakýkoli skript:

```bash
python 1_promenne.py
python 2_Datove_typy.py
```

## Cesta učení

Doporučuje se pracovat se soubory v číselném pořadí:
1. Začněte s `1_promenne.py` a pochopte proměnné
2. Pokračujte na `2_Datove_typy.py` a učte se o různých datových typech

## Tipy pro učení

- Spusťte skripty a experimentujte se změnami kódu
- Zkuste psát své vlastní příklady
- Použijte interaktivní shell Pythonu (`python` nebo `python -i filename.py`) k prozkoumávání konceptů
- Neváhejte tisknout proměnné a kontrolovat jejich typy pomocí `type()`
